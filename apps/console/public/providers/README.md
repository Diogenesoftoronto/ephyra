# Provider marks

Locally bundled marks identify supported telemetry providers. `sources.json` records the exact download URL and SHA-256 digest for each file. Simple Icons SVGs are distributed under CC0; brand names and marks remain their owners' trademarks. Axiom, BugSnag and Embrace use icons served by their official sites. These marks indicate connection choices, not sponsorship or affiliation.

Do not replace marks with generated approximations. Runtime onboarding makes no third-party image requests.
