# Agent logos

Local, unmodified SVGs used only to identify the recorded agent harness. No requests go to these
brands when the console renders a badge. These marks do not imply endorsement of Ephyra.

- `amp.svg`: [Amp press kit](https://ampcode.com/press-kit), [app icon](https://ampcode.com/app-icon.svg).
- `claude.svg`: [Claude](https://claude.com), [site icon](https://claude.com/icon.svg).
- `codex.svg`: [Lobe Icons Codex mark](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/codex.svg),
  used under the included `LOBE-ICONS-LICENSE` (MIT).

Retrieved 2026-11-08. Only the exact `amp`, `codex`, and `claude-code` engine families select a mark.
Unknown identities and missing files use a neutral terminal glyph. The popover preserves the full
engine string, execution kind, runner ID, and project when recorded. A model name or hosting platform
alone never determines the agent logo.
