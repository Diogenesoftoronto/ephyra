# Repository and account marks

- `github.svg`, `gitlab.svg`, `forgejo.svg`, `git.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons),
  under CC0. Product names and trademarks remain their respective owners'. These identify repository destinations.
- `tangled.svg`: Tangled's public favicon from [tangled.org](https://tangled.org/favicon.svg), retained as its mark.
- `notorganic.png`: the existing Not Organic account mark, reused from its portal for the sign-in handoff.
- Ephyra logo files in this directory retain the project's approved identity.

The marks do not imply an authenticated connection. Public GitHub discovery is credential-free; private credentials
and repository verification use the server's existing account flow.
