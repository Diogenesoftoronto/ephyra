# @ephyra/policy

Pure autonomy, threshold, triage, proof and watch helpers; no network or external state is accessed. Package tests cover basic parsing, conservative backend routing, proof presence and watch boundaries. This is an incomplete implementation: callers must not use it for autonomous landing until policy parsing, triage candidate validation, proof and decision-table coverage have been completed and independently verified. Persona and human approvals are explicit inputs, and critical landing mode enforcement remains the caller’s responsibility. Integrations are Unverified.
