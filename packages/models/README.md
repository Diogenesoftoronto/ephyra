# @ephyra/models

Registry configuration validation and deterministic trace extraction. Parser spans are tested offline; extracted values are heuristics, not model confidence or proof.

Not Organic product registration, DPoP and transport clients, TypeSafe, Workers AI and self-hosted System One are **Unverified and not implemented**. No live provider calls have been made. The default token provider throws Unverified. Registry instances are supplied by the caller; it does not create transports.
